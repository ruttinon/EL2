EnergyLink Management - Function Completion Round 12

This round adds simple local run commands.

First time:
  pnpm install
  pnpm db:generate

Run Editor with Engine:
  START_LOCAL_EDITOR_WITH_ENGINE.cmd

Or run manually:
  START_ENGINE.cmd
  START_EDITOR.cmd

Optional:
  START_MONITOR.cmd
  START_WEB_VIEWER.cmd

PowerShell alternatives:
  pnpm check:local
  pnpm start:local
  pnpm start:engine
  pnpm start:editor
  pnpm start:monitor
  pnpm start:web-viewer

No Login / User / Password is added.
No generated runtime values are added.
